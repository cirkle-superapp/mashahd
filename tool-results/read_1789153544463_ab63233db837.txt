   589→# 14. P2P DOWNLOAD STRATEGY
   590→
   591→For each segment request:
   592→
   593→```text
   594→1. Determine whether segment is available from peers.
   595→2. Request from eligible P2P peer(s).
   596→3. Keep HTTP fallback available.
   597→4. If peer delivery is slower than configured threshold:
   598→       cancel/ignore the peer request
   599→       retrieve via HTTP.
   600→5. If peer is unavailable:
   601→       HTTP immediately.
   602→6. Verify received data.
   603→7. Feed valid media into the normal HLS/MSE pipeline.
   604→```
   605→
   606→The player must never wait indefinitely for P2P.
   607→
   608→Use bounded timeouts.
