     1→# Project Worklog — YouTube-like Website
     2→
     3→Project root: `/home/z/my-project`
     4→Goal: Build a YouTube-like video sharing website using Next.js 16 (App Router), TypeScript, Tailwind CSS 4, shadcn/ui, Prisma + SQLite.
     5→
     6→## Architecture decisions
     7→- Single user-visible route `/` (per project rules). Navigation between Home / Watch / Channel / Search / Trending / Subscriptions / History / Liked is done client-side via a Zustand store, synced to URL query params (`?v=watch&id=...` etc.) so browser back/forward still works.
     8→- All data lives in SQLite via Prisma. Models: `Channel`, `Video`, `Comment`, `Category`.
     9→- API routes under `src/app/api/...` are the only data source for the client.
    10→- Real video thumbnails fetched via `z-ai image-search` (OSS-hosted, embeddable URLs). Channel avatars via DiceBear HTTP API (deterministic, no fetch needed). Channel banners via CSS gradients. Video playback via Google's public sample MP4s.
    11→- Theme: dark mode default (YouTube-like), with next-themes toggle. Red accent color (`oklch` red) instead of default neutral — feels like YouTube without being indigo/blue.
